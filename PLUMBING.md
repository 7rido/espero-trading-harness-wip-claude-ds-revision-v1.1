# Plumbing window

A plumbing run is a **mechanics test**, not evidence. It may only run inside a dated window, and the
books it writes are void for any performance claim. The gate refuses `--allow-plumbing` without a
valid window naming the strategy and an expiry.

```plumbing
strategy: sma
purpose: continuous mechanics run while E1 records; fills, stops, funding and the journal
         end to end; not a strategy test and not evidence
started: 2026-10-30
expires: 2026-12-31
owner: account holder
claims: none - books are demo data, void for any performance claim, discarded at expiry
```

# Plumbing window

A plumbing run is a **mechanics test**, not evidence. It may only run inside a dated window, and the
books it writes are void for any performance claim. The gate refuses `--allow-plumbing` without a
valid window naming the strategy and an expiry.

```plumbing
strategy: sma
purpose: prove fills, stops, funding and the journal end to end; not a strategy test
started: 2026-10-30
expires: 2026-11-02
owner: account holder
claims: none - books are demo data and are discarded at expiry
```
